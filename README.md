# メンタルヘルス・マネジメント 2026 回答シート

問題集の問題を見ながら、スマホで **1〜4 の回答を記録していく** ための回答シートです。
問題文に指で ○ や × を書き込めて、あとから回答を見返したり、○付けしたりできます。
本番のように **50問を時間を計って解く「実戦形式」** もあります。
**「過去問題集」と「テキスト問題集」の2冊** を切り替えて使えます（記録・正解データ・問題文は問題集ごと）。

**公開URL: https://ksa02g.github.io/MM2026/**

- 本体は **`index.html` 1つだけ**（ライブラリ・ビルド・通信すべて不要）
  ※ 同梱の `apple-touch-icon.png` と `manifest.json` は、
    ホーム画面に追加したときのアイコン用です。なくても動きます
- 完全オフライン動作
- 回答の記録も正解データも問題文・解説も手書きメモも、**端末のブラウザ（localStorage）の中にだけ** 保存します。
  アプリは公開していますが、記録や正解がどこかへ送られることはありません

## 問題の構成

どちらも全7章で、すべて 1〜4 の4択です。

| 問題集 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 計 |
|---|---|---|---|---|---|---|---|---|
| 過去問題集 | 46 | 15 | 15 | 41 | 30 | 23 | 19 | 189 |
| テキスト問題集 | 50 | 33 | 24 | 41 | 37 | 26 | 23 | 234 |

- **過去問題集** … 過去問を章ごとに集めた問題集。問題番号は本と同じ（第1章 第1問〜）
- **テキスト問題集** … 節ごとの解説のあとに「試験問題を解いてみよう！」が載っているテキスト。
  アプリでは章ごとに出てくる順に第1問〜と通し番号にし、本の節と「問題N」は問題文の右上に出します
  （例「2 労働者にみられる心の健康問題・問題1」。節の見出しのページをスキャンしていない所は「問題N」だけ）

問題数は `index.html` の `BOOKS` に書いてあります。

### 問題集の切り替え

ホームのいちばん上の「過去問題集｜テキスト問題集」で切り替えます（切り替えると読み込み直します）。
記録・実戦形式・正解データ・問題文と解説は問題集ごとに別々に保存するので、混ざりません。手書きメモは回ごとです。

### 実戦形式

本番のように、全189問から **50問** を選んで、時間を計りながら解きます。

- **出題数** — 各章の問題数の比で50問を割り振ります: 第1章 12問・第2章 4問・第3章 4問・第4章 11問・第5章 8問・第6章 6問・第7章 5問。
  各章の中からランダムに選び、**章の順・問題番号の順** に並べて出します
- **同じ問題を続けて出さない** — 出題した問題を覚えておき、章ごとに **まだ出していない問題から** 選びます（リングバッファ）。
  1〜3回目で150問を出し、4回目は残りの39問＋次の周の11問、5回目からは次の周の残りから選びます。
  周が替わった直後も、前回の50問とは重なりません。ホームの「実戦形式」の見出しに、この周でまだ出していない問題の数を出します
- 出題が確定するのは **最初に回答したとき** です。1問も答えずにやめた回は記録せず、その50問は次の回にまわります
- **時間** — 回答画面を開いているあいだだけ数えます（上に「経過 12:34」）。問題ごとにも、その問題を表示していた時間を記録します。
  アプリを裏に回したり、ほかの画面へ移ったりすると止まります。目安は本試験と同じ **120分（1問あたり 2分24秒）**
- **途中でやめる** — 左上の ‹ で **中断**（時間も止まり、ホームの「続きを解く」で再開）。
  右上の **「終了」** で採点して結果へ（未回答は不正解として採点）。50問まで解いたときも「終了して採点する」から
- 終了した回は答えを直せません。結果と解説（手書きメモつき）を見られます
- 回答のしかたは通常の回と同じです（0.5秒で次へ・自信なし・取り消し・手書きメモ）。10マスは出題した順に10問ずつ、番号は 1〜50
- 問題数と時間の目安は `index.html` の `MOCK_N` `MOCK_MIN` で変えられます（章ごとの数は、問題数の比で自動で決まります）

### 自信なし

回答はしたけれど自信がない問題に、あとで見直すための印を付けます。

- **先に「自信なし」を押してから 1〜4 を押す** と、いつも通り 0.5 秒後に次の問題へ進みます
- 1〜4 を押したあと、次へ進むまでの 0.5 秒のあいだに「自信なし」を押しても印が付きます（印が付いたのを見せてから進みます）
- 「自信なし」だけを押しても次へは進みません。もう一度押すと印が外れます
- 印は回答とは別に保存します。答えを「取り消し」ても印は残り、答えを選び直しても印は外れません（外すときは「自信なし」をもう一度）
- 印の付いた問題は、10マスや回答一覧・○付けに **?** の印が付きます。回答一覧と○付けでは「自信なし」で絞り込めます

### 手書きメモ

回答画面の問題文に、指で ○ や × などを書き込めます（選択肢ごとに適切・不適切の印を付ける、など）。

- 問題文の右下の **ペン** を押すと書けるようになります。もう一度押すと閉じます
- ペンのあいだは **問題文が動きません**（書いているときに画面がずれないように）。続きを読むときはペンを閉じてスクロールします
- 書いている途中にほかの指や手のひらが触れても、最初に触れた指の線だけを書きます
- 次の問題へ移ると、ペンは自動で閉じます（まずスクロールして問題を読めるように）
- 道具: ペン / 消しゴム（なぞった線を消す）/ ↶ 1つ戻す / ごみ箱（その問題のメモを全部消す。↶ で戻せる）
- メモは **回ごと・問題ごと** に、書いた瞬間に保存されます。ペンを閉じていても、メモのある問題はペンのボタンに赤い点が付きます
- 記録（回）を削除すると、その回のメモも消えます
- 問題文は幅を固定して組み、画面に合わせて拡大・縮小しているので、縦横を変えてもメモの位置はずれません

### 記録の扱い

- 「新しく解きはじめる」を押すたびに、**別の回** として記録します（同じ問題集を何周もする想定）
- 記録の日付は **その回で最初に回答した日** です。続きを別の日に解いても、日付は変わりません
- 1問も答えずにホームへ戻った回は保存しません
- 実戦形式の記録は、通常の記録とは別の場所（`mhm2026-mock`）に、出題の記録と一緒に保存します
- 回答はタップした瞬間に保存されます。途中でアプリを閉じても大丈夫です

## 正解データの取り込み

正解は公開リポジトリに載せないよう、**アプリには埋め込まず、端末ごとに取り込みます。**
取り込んだ正解は、すべての回の○付けに使われます。

### 取り込みかた

- **リンクをタップする** — `https://ksa02g.github.io/MM2026/#key=3142…` の形の取り込み用リンクを開くと、
  確認画面が出るので「登録する」。開いた直後にアドレス欄からは正解を消します
  （`#` より後ろはサーバーに送られないので、GitHub 側にも残りません）
- **貼り付ける** — ホーム →「正解データ」で、リンクや数字を貼り付けて「読み取る」→「登録する」
- テキスト問題集のリンクには `b=2` が付きます（`…/MM2026/#b=2&key=…&ex=…`）。
  もう一方の問題集を開いているときにリンクを開いたり貼り付けたりすると、その問題集に切り替えてから取り込みます。
  数字だけを貼り付けたときは、いま開いている問題集の正解として読みます

> **iPhone で「ホーム画面に追加」して使っている場合は、貼り付けてください。**
> ホーム画面のアプリは Safari と保存場所が別なので、リンクをタップして Safari で取り込んでも、
> ホーム画面のアプリには入りません。リンクを長押しでコピーして、アプリの「正解データ」に貼り付けます。

### 書きかた

貼り付け欄には、次のどちらの形でも入れられます。

```text
3142231441 2314231441 …          ← 189問ぶんを続けて（空白・改行は自由）

第1章: 3142231441 2314231441 …   ← 章ごとの行で（書いた章だけを更新）
第2章: 2314231441 23142
```

- 正解が分からない問題は `-`（`?` `ー` も可）。○付けの対象から外れます
- 全角数字でもかまいません
- 問題数が合わないときは、どの章が何問ぶんだったかを表示して、登録しません
- 「正解データ」画面で、登録されている正解を10問ずつ区切って確認できます

## 問題文・解説

問題文と解説の文章も問題集の著作物なので、公開リポジトリには **暗号化したファイル（過去問題集は `explain.bin`、テキスト問題集は `explain2.bin`）だけ** を置いています。
中身は AES-GCM で暗号化してあり、鍵を知らなければ読めません。

- 取り込み用リンクの `&ex=…` が鍵です。正解と同じリンクで取り込むと、`explain.bin` を取得して端末の中で復号し、
  ブラウザに保存します（取り込むときだけ通信します。あとはオフラインで読めます）
- 鍵は `#` より後ろにあるので、サーバーには送られません
- 起動したときに `explain.bin` が新しくなっていれば（誤字を直したときなど）、自動で入れ替えます
- 「正解データ」画面で、読み込み直し・削除ができます
- 問題文は問題集の 2〜137ページ、解説は「解答・解説」ページ（139〜238ページ）から書き起こしたものです。
  原本の誤植は直さずに、そのまま写しています
- 問題文の図表は、表は表として組み直しています（第3章第12問）。○×の組合せの選択肢は A〜D の見出しつきの表に、
  穴埋めの空欄は ［ア］ のような枠にしています
- テキスト問題集は、問題のある見開きのスキャン（本の 4〜350ページのうち 95見開き）から書き起こしました。
  解説は各問題の横の「解答・解説」欄の内容（選択肢ごとの 適切／不適切 と短い説明）です。
  正解は全問、解説欄の判定（適切／不適切・○×・該当しない など）と食い違いがないことを確かめています

### 作り直しかた（PC）

平文の問題文・解説（`explain.json`）と鍵（`ex.key`）は、MyApps の `.private/mhm2026/` にあります（Git の対象外）。
問題文の書き起こしの元データは `.private/mhm2026/questions/` です。

```powershell
py -3 .private\mhm2026\build_explain.py      # explain.json を暗号化して explain.bin を作り直す
py -3 .private\mhm2026\build_explain.py --questions .private\mhm2026\questions
                                              # 問題文を書き起こしから入れ直してから作り直す
```

鍵はそのまま使い回すので、スマホ側で取り込み直す必要はありません。`explain.bin` を push すれば、次に開いたときに入れ替わります。

テキスト問題集は `.private/mhm2026/book2/` にあります（書き起こしは `questions/g1.json`〜`g9.json`、鍵は `ex2.key`）。

```powershell
py -3 .private\mhm2026uild_book2.py       # 書き起こしから explain2.json と explain2.bin、取り込み用リンク（book2/link2.txt）を作る
```

正解と解説欄の判定が食い違う問題や、節の中で問題番号が飛んでいる所があると、作らずに知らせます。
章ごとの問題数が変わったときは、`index.html` の `BOOKS` も合わせます（合っていないと知らせます）。

## 保存について（大事）

- 記録は **その端末・そのブラウザの中だけ** に保存されます。別のスマホや PC とは共有されません
- 保存場所は問題集ごとに別です（過去問題集は `mhm2026-…`、テキスト問題集は `mhm2026-b2-…`）
- ブラウザの「履歴とWebサイトデータを消去」をすると記録も消えます
- **iPhone は「ホーム画面に追加」して使ってください。** Safari のまま使っていると、
  しばらく開かなかったときに Safari が記録を自動で消すことがあります

### ホーム画面に追加する（iPhone）

1. Safari で https://ksa02g.github.io/MM2026/ を開く
2. 共有ボタン <kbd>□↑</kbd> → **「ホーム画面に追加」** → 「追加」

Android の Chrome では、メニュー → 「ホーム画面に追加」です。

## 公開のしくみ

このフォルダは非公開の MyApps リポジトリで管理し、`main` に push すると
GitHub Actions（`.github/workflows/mirror-public.yml`）が公開リポジトリ `ksa02g/MM2026` へ反映します。
`MM2026` の **Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`** で配信しています。

## PC で試す

`index.html` をダブルクリックしてブラウザで開くだけ。キーボードでも操作できます。

| <kbd>1</kbd>〜<kbd>4</kbd> | 回答して次へ |
